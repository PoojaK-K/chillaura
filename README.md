# 💜 Chillaura

> **A calming, aesthetic web application that offers emotional support, personalized mood responses, and daily affirmations to promote mental well-being.**

---

## 🌸 Overview

Chillaura is a lightweight wellness companion designed to provide a peaceful digital space where users can express their emotions and receive comforting, mood-based responses.

Built using pure **HTML**, **CSS**, and **JavaScript**, the application focuses on simplicity, elegant design, and emotional wellness. It also stores daily affirmations locally, allowing users to revisit positive messages over time.

---

## ✨ Features

### 😊 Mood Check-In

* Select your current mood
* Personalized supportive messages
* Friendly and comforting interaction

### 💜 Personalized Companion

* Name your own vibe partner
* Customized responses using the chosen name

### 🌼 Daily Affirmations

* Random motivational affirmations
* Automatically saved after every interaction
* Displays the last 7 affirmations

### 💾 Local Storage

* Saves affirmation history in the browser
* No login or database required
* Data persists across browser sessions

### 🎨 Aesthetic User Interface

* Animated pastel gradient background
* Glassmorphism-inspired design
* Smooth animations and transitions
* Responsive centered layout

---

## 🎭 Supported Moods

* 🌸 Happy
* 🌧️ Sad
* 🔥 Angry
* 🌙 Tired

Each mood displays a unique encouraging message to help users feel supported and understood.

```bash

```

No installation or external dependencies are required.
